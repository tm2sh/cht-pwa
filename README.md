# UI Мессенджера

[Открыть макет в GitHub Pages](https://tm2sh.github.io/cht-pwa/)

## Добавление PWA на iOS

1. Откройте [макет](https://tm2sh.github.io/cht-pwa/) в **Safari** на iPhone.
2. Нажмите **«Поделиться»**. В компактном интерфейсе Safari сначала откройте меню страницы.
3. Выберите **«На экран „Домой“»**.
4. Если есть переключатель **«Открыть как веб-приложение»**, включите его.
5. Нажмите **«Добавить»**, затем запустите приложение через появившуюся иконку на домашнем экране.

[Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios)

## Добавление PWA на Android

1. Откройте [макет](https://tm2sh.github.io/cht-pwa/) в **Google Chrome** на телефоне.
2. Откройте меню **⋮** справа от адресной строки.
3. Выберите **«Установить и создать ярлык» → «Установить»**.
4. Подтвердите установку и запустите приложение через его иконку.

[Инструкция Google Chrome](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ru)
